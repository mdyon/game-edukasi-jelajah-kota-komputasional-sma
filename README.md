# Kota Komputasional SMA Adventure
Game edukasi Informatika SMA dengan kota 2D yang dapat dijelajahi, rute, karakter, gedung, NPC, misi berurutan, XP, nyawa, dan final mission.

## Kontrol
- WASD / Arrow Keys: bergerak
- Enter / tombol Interaksi: membuka misi terdekat
- Klik gedung: membuka misi jika area sudah terbuka

## GitHub Pages
Upload `index.html` ke root repository public. Buka Settings > Pages > Source: Deploy from a branch > Branch: main > Folder: / (root) > Save.
